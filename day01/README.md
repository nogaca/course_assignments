# Day 01 Assignment

In our first assignment, we created a personal website using GitHub Pages and AI.

## What I did

I created a GitHub repository called `nogaca.github.io` and used ChatGPT to help me build my website.

I wanted the website to include a short introduction about myself, my research, and my hobbies.

I used ChatGPT to help me write the HTML, CSS, and Markdown files, and to make changes to the design until I was happy with the result.

You can see my website here: https://nogaca.github.io/

Here are some examples of the prompts I used while working with ChatGPT (reworded from my original requests):

1. Help me create a personal website using GitHub Pages. I have never done this before, so guide me step by step and explain them.

2. I want a cream background with pink and yellow accents. Help me choose a color palette and apply it to my website.
