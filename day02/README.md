# Day 02 Assigment
In this week's assignment, we practiced how to clone a repository from GitHub and work on it locally on our computers.

Luckily, I already had Git, VSCode and Python3 installed on my computer, so I could get started right away!

## What I did

1. Created a new public GitHub repository called `course_assignments`.
2. Cloned the repository to my computer using VSCode.
3. Created a folder called `day02`.
4. Created a Python file called `hello.py`.
5. Wrote a simple Python program that prints "Hello World".
6. Opened the terminal in VSCode and ran the program using:
   python3 day02/hello.py 
7. Verified that the program printed "Hello World" successfully.

## What I learned

- How to create and clone a GitHub repository.
- How to create and run a Python file in VSCode.
- How to use the terminal from VSCode to run Python programs.
